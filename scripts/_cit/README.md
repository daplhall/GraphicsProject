# Usage
## Header
adding header
```
cit add header module/header.[h, hpp]
```
removing header
```
cit rm header module/header.[h, hpp]
```
## Module
adding header
```
cit add module <full module path>
```
removing header
```
cit rm module <full module path>
```
removing a module will remove everything!
## Source
adding header
```
cit add source module/header.[c,cpp]
```
removing header
```
cit rm source module/header.[c, cpp]
```
## tests
adding header
```
cit add test module/header.[c/cpp]
```
removing header
```
cit rm test module/tests.[c/cpp]
```

## interface 
adding interface
```
cit add interface module/interface
```
removing interface
```
cit rm interface module/myinterface
```
creates an interface and tests and a source file
